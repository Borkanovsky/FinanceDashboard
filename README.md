# Finance Dashboard

A mobile financial analysis app built with React Native. Search any publicly traded US company and view real-time financial data, historical charts, key ratios, and an interactive DCF valuation calculator.

## Features

- **Company Search**: Autocomplete search for any publicly traded US company
- **Overview Dashboard**: Current price, daily change, 1-year price chart, market cap, sector, 52-week range
- **Financial Statements**: 5 years of income statement, balance sheet, and cash flow data with bar charts
- **Key Ratios**: 20+ financial ratios organized by category (Valuation, Profitability, Leverage, Efficiency)
- **DCF Calculator**: Interactive discounted cash flow model with adjustable growth rate, discount rate, and terminal multiple. Implied share price updates in real-time.

## Tech Stack

- React Native (Expo)
- Financial Modeling Prep API
- react-native-chart-kit
- React Navigation
